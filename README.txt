WEEK 1 DATA ANALYSIS PROJECT
============================

Files:
- Week1_EDA_Report.docx : report to upload in the assignment's report field
- analysis.py           : runnable Python source code
- iris_dataset.csv      : dataset used
- iris_cleaned.csv      : cleaned output
- correlation_matrix.csv: feature correlations
- charts/               : figures used in the report

Run:
    pip install pandas numpy matplotlib
    python analysis.py

Submission checklist:
1. Upload Week1_EDA_Report.docx in "Upload your report file".
2. If you upload the code to GitHub, paste your repository URL in the optional GitHub field.
3. Paste a short description in the description box. Suggested text:
   "This project uses Python, Pandas, NumPy, and Matplotlib to inspect and clean the Iris dataset and perform exploratory data analysis. It includes data-quality checks, descriptive statistics, charts, key findings, and a reproducible Python script."
4. Check that your report and code reflect the files you submit.

Dataset note:
The classic Iris dataset was loaded from scikit-learn's bundled copy of the public Iris dataset (originally associated with the UCI Machine Learning Repository).
